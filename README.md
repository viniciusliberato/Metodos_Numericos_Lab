# Laboratórios de Métodos Numéricos

## Descrição
Este repositório contém os laboratórios, códigos e datasets utilizados nos estudos de Métodos Numéricos. 

## Estrutura do Projeto
* **`.devcontainer/`**: Configurações do contêiner Docker para o VS Code.
* **`requirements.txt`**: Lista centralizada das dependências do Python (como `ipykernel`, `ISLP`, `pandas`, etc.).
* **`lab1.ipynb`**: Notebook de desenvolvimento do primeiro laboratório.
* **`limpeza.py`**: Scripts em Python para tratamento inicial dos dados.
* **Datasets (`.csv`)**: Bases de dados locais utilizadas para as regressões e modelagens.

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Ambiente e Virtualização:** Docker, VS Code Dev Containers
* **Controle de Versão:** Git e GitHub
* **Ferramentas de Análise:** Jupyter Notebooks, bibliotecas (ILSP, pandas, matplotlib etc.) de modelagem e manipulação de dados.
